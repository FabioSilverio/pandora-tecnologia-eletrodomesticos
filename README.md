# Pandora Tecnologia Landing Page

Landing page estática para a Pandora Tecnologia, focada em lojas de eletrodomésticos.

## Arquivos

- `index.html`: estrutura da página
- `styles.css`: layout, cores e responsividade
- `script.js`: animações e interações
- `assets/img/`: imagens da página

## Publicação

O repositório já está preparado para publicar no GitHub Pages via GitHub Actions.
